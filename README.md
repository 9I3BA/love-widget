# 💖 Love Widget  
*Android-виджеты для пар: «Дней вместе» и «Мини-галерея»*  

## 🎯 Описание и цели  

**Love Widget** — автономное Android-приложение для пар, созданное с акцентом на локальное хранение и минимализм.  

🔹 **Основные возможности:**  
- 🕒 Отображение **количества дней вместе** с плавным обновлением (в т.ч. в виджете),  
- 📅 Управление **напоминаниями** (годовщины, дни рождения) — даже прошедшие,  
- 📸 Работа с **фотографиями**: аватары, главное фото, мини-галерея (до 4 изображений),  
- 📱 Два **виджета на рабочий стол**:  
  - `Дней вместе` — цифровой таймер в реальном времени,  
  - `Мини-галерея` — показ 4 избранных фото с возможностью обновления из приложения.  

🔒 Все данные хранятся **локально** (SharedPreferences / внутренняя память).  
📱 Поддержка Android 7.0+ (API ≥24).  
💡 Приложение **не требует интернета**, аккаунтов или разрешений за пределами `READ_EXTERNAL_STORAGE` (для фото).

## 🛠 Используемые технологии  

| Категория       | Инструменты и библиотеки                                                                                |
|-----------------|---------------------------------------------------------------------------------------------------------|
| **Язык**        | Kotlin                                                                                                  |
| **UI/UX**       | View-based (XML), `AppCompat`, `ConstraintLayout`, `RecyclerView`                                       |
| **Хранение**    | `SharedPreferences`, внутреннее хранилище (`Context.filesDir`)                                          |
| **Виджеты**     | `AppWidgetProvider`, `RemoteViews`, `PendingIntent`                                                     |
| **Фон**         | `WorkManager` (для ежедневного обновления виджета), `BroadcastReceiver` (обновление при изменении даты) |
| **Фото**        | `Bitmap`, `MediaStore` (для загрузки из галереи), сжатие и кэширование в памяти                         |
| **Дата/время**  | `java.time.LocalDate` (через desugaring для API <26), `ChronoUnit.DAYS`                                 |
| **Тестирование**| `JUnit`, `Espresso` (частично), ручное тестирование на физических устройствах                           |
| **Сборка**      | Gradle (Kotlin DSL), `minSdk 24`, `targetSdk 34`                                                        |

> 📌 В проекте используется **desugaring** (`coreLibraryDesugaring`) для поддержки Java 8+ API (включая `java.time`) на старых версиях Android.

## 📖 Инструкция по использованию

Приложение рассчитано на **одну пару** — все данные хранятся локально, без регистрации.

### 1. Первый запуск  
- Откройте приложение → появится экран приветствия (**`WelcomeActivity`**).  
- Нажмите **«Начать»** → перейдёте в **настройку профиля** (`ProfileSetupActivity`).  
- Укажите:  
  - ✅ **Имена партнёров** (отображаются в интерфейсе),  
  - ✅ **Дата начала отношений** (через встроенный календарь — `DatePickerActivity`),  
  - ✅ (Опционально) загрузите **аватары** и **главное фото** из галереи.  
- Нажмите **«Готово»** → откроется главный экран (**`HomeActivity`**).

### 2. Главный экран (`HomeActivity`)  
Здесь отображается:  
- 🕒 **Сколько дней вы вместе** — обновляется ежедневно в 00:00 (через `WorkManager`),  
- 📸 **Главное фото** (если загружено),  
- 📌 Список **напоминаний** (годовщин, дней рождений и т.п.).  

#### Действия:  
- ➕ **Добавить напоминание** — нажмите `+` → `CreateReminderActivity`:  
  - Укажите название, дату, тип («Ежегодно» / «Однократно»).  
  - Прошедшие даты **отображаются серым**, но остаются в списке.  
- 📝 **Редактировать напоминание** — нажмите на элемент → откроется `NoteActivity`.  
- 🗑️ **Удалить** — свайп влево (или долгое нажатие + корзина).  
- ⚙️ **Настройки** — значок шестерёнки (`ic_settings`) → `SettingsActivity`:  
  - Изменить профиль (имена, дату отношений, фото),  
  - Включить/отключить автозагрузку фото из галереи.

### 3. Виджеты  
Добавьте на рабочий стол:  
- **«Дней вместе»**:  
  - Показывает текущий счётчик (например, *«1283 дня»*),  
  - Обновляется автоматически каждые 24 ч + при изменении даты в приложении.  
- **«Мини-галерея»**:  
  - Отображает **4 последних фото** из списка напоминаний и главного фото,  
  - Нажмите на виджет → откроется `HomeActivity`.

> 💡 **Совет**: фото в мини-галерее обновляются только при редактировании напоминаний или профиля — перетаскивание/добавление «на лету» пока не поддерживается.
